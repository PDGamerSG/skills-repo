# Skills

Agent skills for building projects, researching ideas, designing interfaces and
finishing work. Each skill has a readable folder under [`skills/`](skills), with
its instructions in `SKILL.md` and the resources it needs alongside it.

Choose the skills that fit the task. The collection includes skills preserved
from Windows; their presence does not establish usage or working runtime support.

## Install

Clone the repo, then copy only the folders you choose:

```sh
git clone https://github.com/PDGamerSG/skills-repo.git
cp -R skills-repo/skills/namecheap ~/.codex/skills/
# Claude Code uses ~/.claude/skills/ instead.
```

Compare an existing destination before copying so you preserve customizations.
On Windows, copy the selected folder with Explorer or PowerShell into the skill
directory used by that agent.

Two alternatives have their own folders:

- [`variants/codex/skill-creator`](variants/codex/skill-creator/SKILL.md): the
  Codex-specific authoring guide. Choose it instead of the primary skill-creator
  when appropriate; don't install both under the same name.
- [`variants/claude/research`](variants/claude/research/SKILL.md): the original
  outline workflow needed by `research-add-*`, `research-deep` and `research-report`.

Skill instructions do not install packages, browser integrations, hooks, model
access or account sessions. Check the selected skill's prerequisites. Credentials
stay in private local storage.
